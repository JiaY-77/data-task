# 亚马逊广告投放数据分析 · 交付

> 业务目标：判断这组亚马逊店铺「近 12 个月广告投放明细」的健康度，并给出可执行的优化建议。

## 0. 一句话结论

广告花费 700.93 万、整体 ACOS 30.22%（健康区间），但其中 **13.7%（95.69 万）花在了零转化上**；且该损耗在活动 / 匹配方式 / 站点三个维度上**几乎没有差异**（13.0%~14.0%），说明是**投放机制层面的普遍损耗**，建议用「关键词级零转化止损 + 否定词治理」整体处理，而非削减某个具体广告活动。

## 1. 我理解的业务问题

- 任务要我回答的是：这组投放**健不健康**、钱**该往哪调**。
- 我把它拆成两个可验证的子问题：
  1. **效率水位**：整体 ACOS / CPC / 转化率在什么水平？（可量化）
  2. **损耗归因**：有没有明显的低效环节，且能不能定位到具体对象？（可量化）
- 我把两个问题**合并为主线**（而不是只做一个），因为第 2 个问题的答案依赖第 1 个确定的口径 —— 先说清水位，再说损耗，最后回答「能不能归因」。

## 2. 数据长什么样

| 项 | 实际情况 |
|---|---|
| 规模 | 150,000 行 × 13 列（13.1 MB） |
| 记录粒度 | 广告报表行（`report_id` 唯一，一行 = 一条投放记录） |
| 时间跨度 | 2025-08-01 ~ 2026-07-16（约 11.5 个月，**末月仅 16/31 天**） |
| 维度 | campaign（5）· match_type（4）· keyword（60）· marketplace（5） |
| 指标 | impressions / clicks / spend / orders / sales / acos |

### 我发现的数据问题（以及我的处理）

1. **`spend` 有负值**（458 行，合计 -2.15 万）→ 判定为冲红 / 账务调整；**保留原值不清洗**（它属于真实账务），但在口径中明确说明。
2. **`acos` 空值 31%** → 因为 `sales=0` 的行算不出 ACOS；**不使用该列做聚合**，改为自己算 `sum(spend)/sum(sales)`，避免被空值误导。
3. **`rating` 缺失 78%** → 与本次分析主题无关，不做评分归因，也不据此下任何结论。
4. **末月只有 16 天** → 趋势图与所有「最近在跌」类结论都不采用该月。

## 3. 我是怎么分析的（决策路径）

1. **先体检，不先算**：看字段类型、空值、取值范围 → 一上来就发现 `spend` 有负值、`acos` 空值 31%，于是**先定口径再动数**。
2. **先算水位**：整体 ACOS 30.22%、CPC 1.07 元、转化率约 7.0% —— 先知道基线在哪，后面才能说「好/坏」。
3. **找损耗点**：把「花了钱但零订单」的行单独拎出来 → 95.69 万（13.7%）。
4. **试着归因**：按 campaign / match_type / marketplace 三个维度拆零转化占比 → **三者几乎完全一致**。
5. **因此改方向**：既然归因不到具体对象，就**放弃「砍某个活动」的建议**，改从机制层面给方案。
6. **排除的方向**：关键词「最佳 / 最差」榜单 —— 各词花费接近（1.7% 上下）、ACOS 接近（29%~32%），差异落在噪声内，**不做排名解读**。

## 4. 关键发现（每条带数字 + 口径）

1. **整体投放效率健康**：花费 **700.93 万**、广告销售额 **2319.11 万** → **ACOS 30.22%**；CPC 1.07 元；广告订单 45.56 万；平均转化率 7.0%。
2. **13.7% 的花费没有产生任何订单**：**95.69 万**，涉及 44,990 行记录。
3. **零转化在三个维度上均匀分布**：campaign 13.0%~14.0%、match_type 13.5%~13.9%、marketplace 13.3%~13.9%（各维度极差均 < 1 个百分点）。
4. **各活动 / 各匹配方式的效率也高度一致**：5 个 campaign 的 ACOS 全部落在 30.0%~30.4%；4 种 match_type 同样落在 30.0%~30.4%。

> **口径说明**：金额按列直接求和，包含 458 行负花费（冲红）；ACOS = `sum(spend)/sum(sales)`，**仅含广告销售额、不含自然流量**（因此不等于 TACOS）；零转化定义 = `spend > 0 且 orders = 0`。

## 6. 所以，建议做什么

| 建议 | 依据 | 预期影响 | 风险 |
|---|---|---|---|
| 建立**关键词级零转化止损**规则（连续 N 天零转化 → 自动降预算/暂停） | 13.7% 花费零转化、44990 行记录 | 若回收一半，约省 **48 万**；相当于整体 ACOS 从 30.2% 降到约 **28.2%** | 可能误伤决策周期长的品类词，需设观察期 |
| 做一轮**否定词治理**（零转化词加否定/精确否定） | 零转化在关键词上分布均匀（无单一大户） | 降低无效点击，改善 CPC 效率 | 需人工复核清单，避免否定掉长尾转化词 |
| **不削减现有广告活动** | 5 个活动 ACOS 差异 < 0.4 个百分点 | 避免过度优化反而丢量 | — |
| 补全末月数据后再评估季节性 | 末月仅 16/31 天 | 避免误判季度走势 | 需等数据完整 |

## 7. 我的判断的边界（诚实）

- **数据局限**：末月只有 16/31 天；`rating` 缺失 78%；`acos` 列缺失 31%（未使用该列，改为自行计算）。
- **方法局限**：ACOS 只含广告销售额、**不含自然流量**，因此不等于 TACOS——真实的整体效率可能优于 30.22%；负花费（-2.15 万）未做剥离，包含在总花费内。
- **结论强度**：
  - 强：整体效率水位（30.22%）、零转化金额（95.69 万 / 13.7%）—— 全量数据、口径明确。
  - **弱：「各维度均匀 → 机制层面损耗」这条推断** —— 均匀分布也可能源于**数据本身高度同质**（例如报表由统一规则生成、或投放策略本就一致），我无法从这份数据区分这两种解释。因此**不建议**仅凭此下"投放机制有问题"的结论，而应视为"本次数据未提供归因证据"。
- 没有做的事：关键词排名解读（各词花费 1.7% 上下、ACOS 29%~32%，差异在噪声内，排名不可靠）。

## 8. AI 协作记录

- **我让 AI 做的**：数据体检脚本、KPI / ACOS 结构计算、绘图、README 结构。
- **我自己做的**：确定分析主线（效率水位 + 损耗归因）、判断「各维度无差异」不能当归因证据、核对每个数字、写口径说明。
- **我怎么验证 AI 的输出**：
  1. 总量与分组之和交叉核对（各活动花费相加 = 总额）；
  2. 关键指标换算法复算（ACOS 用 `sum(spend)/sum(sales)` 重算，不用数据里那列 `acos`——它有 31% 缺失）；
  3. 抽查前几行确认字段类型判断正确。
- **一个 AI 出错被我抓到的例子**：初版分析把这份**广告数据**当成了「订单/销售明细」——把 `sales` 当"总营收"、算出"客单价"，并**完全漏掉了 ACOS**，还把 `campaign / match_type / keyword` 三个广告核心维度判成"其他"跳过。我发现后**另写了一个广告专项脚本**重做，才拿到正确口径。（这个过程本身说明：AI 给的是草稿，判断要自己做。）
